# EightNights

Celebrate holidays with new items.

**EightNights** is a small decorative mod for Minecraft Beta 1.7.3.

Craft golden candelabra and candles from honey wax, to set up own Festival of Lights!

## Features

- **Candles** - made from honey items (added by mod Foodies).
- **Golden Candelabra** - put up to 9 candles in it. Brightness depends on number of them. Can be extinguished and lit with flint & steel.
- Custom textures and models.
- More coming soon&trade;

## Required dependencies

- **[StationAPI](https://modrinth.com/mod/stationapi)** - version >= **2.0.0-alpha.6.4**
- **[Foodies](https://modrinth.com/mod/foodies)** - version >= **1.1.4** - required because EightNights depend on food items not avaible in vanilla beta 1.7.3.

## Compatibility

- **No known compatibility issues**.
